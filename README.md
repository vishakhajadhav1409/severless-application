# Serverless Student Registration Application

## Project Overview

The Serverless Student Registration Application is a cloud-native web application developed using AWS Serverless services. It allows users to register student information through a web interface, stores the data in Amazon DynamoDB, and processes requests using AWS Lambda behind Amazon API Gateway.

The frontend is hosted on Amazon S3.

---

## AWS Services Used

- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon S3
- AWS IAM
- Amazon CloudWatch
